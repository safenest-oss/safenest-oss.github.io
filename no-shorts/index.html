No Shorts

A tiny Chrome extension that removes YouTube Shorts from your experience.

Add from Chrome Web StoreSource code

What it does

  • Hides Shorts shelves and single Shorts on the home page, subscriptions, search results and recommendations.
  • Removes the "Shorts" entry from the sidebar and menu, and the "Shorts" tab and filter on channel pages.
  • Opens youtube.com/shorts/… links in the regular video player.

It works in Chrome, Edge, Brave and Opera on a computer, and runs only on youtube.com.

Privacy

No Shorts does not collect, store, share or send any data. No analytics, no cookies, no network requests, no special permissions. Read the full privacy policy or check the code yourself.

For a child's profile (Family Link)

A Chrome profile supervised with Google Family Link can only add extensions from the Chrome Web Store. In our tests the child taps Ask a parent and the parent approves with a password. Keep the Family Link setting Extensions (Controls, Google Chrome and web, Advanced settings) turned off, otherwise the child can add extensions without asking.

Limit: a supervised child can still remove or disable the extension without a password. Re-adding it needs your approval again. Ideas to lock it are tracked in the issues.

On phones

The YouTube app and Chrome on Android and iPhone do not support extensions, so No Shorts does not work there. Use YouTube's own Shorts limit instead: Limit Shorts on phones with Family Link.

Honest limits

No Shorts hides Shorts, it does not make YouTube safe, and it does not replace talking to your child. YouTube changes its pages often, so something may slip through. If it does, tell us.
